### 🎯 О проекте
**Reminder Service** — это отказоустойчивый REST API для планирования персональных задач и автоматической рассылки уведомлений. Проект решает проблему своевременного информирования пользователя через удобные ему каналы (Telegram/Email), избавляя от необходимости постоянно проверять список дел вручную.

Основной фокус при разработке был сделан на **автоматизации бизнес-процессов** и **целостности данных** в условиях микросервисного подхода.

### ⚙️ Ключевые архитектурные решения
* **Event Scheduling:** Использование **Quartz/Scheduled** для точного триггеринга уведомлений. Система мониторит базу данных и инициализирует рассылку ровно в момент наступления события.
* **Data Consistency:** Все изменения схемы данных управляются через **Liquibase**, что гарантирует идентичность структуры БД на разных этапах разработки и продакшена.
* **Security First:** Доступ к данным строго разграничен через **Spring Security OAuth2**. Пользователь имеет доступ только к собственным записям.
* **Performance:** Фильтрация, сортировка и пагинация реализованы на уровне SQL-запросов (**JPA/Hibernate**), что минимизирует нагрузку на память приложения при больших объемах данных.

### 🛠 Стек
* **Backend:** Java 21, Spring Boot 3, Spring Security OAuth2.
* **Storage:** PostgreSQL, Hibernate, Liquibase.
* **Infrastructure:** Docker, Docker Compose, Gradle.
* **Messaging:** JavaMailSender, Telegram Bot API.

### 🚀 Запуск
Приложение упаковано в Docker-контейнеры и готово к развертыванию одной командой:
```bash
docker-compose up --build
```
